# VideoCutEditor 0.6.0

映像のトリミングを追加し、実行環境を .NET 11 に更新しました。

## 主な変更

- 「トリミング」を押すと、プレビュー上に切り抜き枠が表示されます。辺や角をドラッグして範囲を調整し、枠の内側をドラッグして移動できます。
- 操作パネルから、上下左右の切り取り量を ±1 px・±10 px で調整できます。設定した範囲は同じ動画から書き出す全クリップに適用されます。
- トリミングを指定すると Re-encode に切り替わります。切り抜き後の幅や高さが奇数の場合は、出力の右端または下端に黒い余白を1 px加えます。

## 配布物

- `VideoCutEditor-0.6.0-win-x64-setup.exe` は、現在の Windows ユーザー向けインストーラーです。管理者権限は不要です。
- `VideoCutEditor-0.6.0-win-x64.zip` は Portable 版です。ZIP を展開し、ファイル一式を同じフォルダーに置いたまま `VideoCutEditor.exe` を起動してください。
- 各配布物の `.sha256` ファイルは、ダウンロード後の整合性確認に使えます。

## 動作環境

- 起動には x64 の .NET 11 Runtime が必要です。Windows App SDK は配布物に含まれています。 [.NET 11 のダウンロード](https://dotnet.microsoft.com/en-us/download/dotnet/11.0)
- ffmpeg と ffprobe は、PATH から自動検出するか、設定画面で指定してください。
- 配布物は未署名のため、Windows から発行元不明の警告が表示される場合があります。
