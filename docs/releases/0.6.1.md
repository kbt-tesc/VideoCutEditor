# VideoCutEditor 0.6.1

## 主な変更

- 「トリミングされた部分だけ表示」をオンにすると、選んだ範囲だけをプレビューできます。この間は枠が消え、操作パネルのボタンで各辺を調整できます。
- INFO ウィンドウの位置とサイズを記憶し、次回起動後も復元します。
- 一部の AV1 動画で、枠より狭く切り出された映像が横に伸びる問題を修正しました。トリミング枠をプレビューの映像に合わせ、選んだ範囲の縦横比で書き出します。

## 配布物

- `VideoCutEditor-0.6.1-win-x64-setup.exe` は、現在の Windows ユーザー向けインストーラーです。管理者権限は不要です。
- `VideoCutEditor-0.6.1-win-x64.zip` は Portable 版です。ZIP を展開し、ファイル一式を同じフォルダーに置いたまま `VideoCutEditor.exe` を起動してください。
- 各配布物の `.sha256` ファイルは、ダウンロード後の整合性確認に使えます。

## 動作環境

- 0.6.0 から .NET 11 に移行しました。.NET ランタイムの同梱を終了したため、起動には別途 x64 の .NET 11 Runtime が必要です。 [.NET 11 のダウンロード](https://dotnet.microsoft.com/en-us/download/dotnet/11.0)
- アプリはアンパッケージ形式で、Windows App SDK は配布物に含まれています。
- ffmpeg と ffprobe は、PATH から自動検出するか、設定画面で指定してください。
- 配布物は未署名のため、Windows から発行元不明の警告が表示される場合があります。
